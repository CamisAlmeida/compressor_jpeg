# compressor_jpeg
Implementar, em Python, um compressor de imagens inspirado no JPEG. O projeto deve integrar
conversão RGB → YCrCb, processamento em blocos, DCT 2D, quantização, varredura zig-zag,
uma codificação simples para cálculo de taxa, reconstrução da imagem e avaliação de qualidade.
Ao final, devem ser comparadas duas formas de calcular a DCT: a implementação matricial
científica.
